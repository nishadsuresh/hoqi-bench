# Kåsa 1976 — "A circle fitting procedure and its error analysis"

**Access:** SECONDARY / general knowledge only. Full text not accessed (paywalled, and the
researcher pass verifying its bibliographic details could not open a primary metadata page
either — see `refs/references.bib`'s note; confidence rests on agreement across independent
secondary aggregators). The method itself is standard and already implemented once before, in the
`quadrature-interferometer-sim` project (`fit_circle_center` in that repo's `src/analysis.py`),
which this project ports directly as its Day 16 baseline — so the *algorithm* is well understood
through that prior implementation and verification, even without having read this specific paper's
original text.

## Citation
Kåsa, I. (1976). *A circle fitting procedure and its error analysis.* IEEE Transactions on
Instrumentation and Measurement, 25(1), 8-14. See `refs/references.bib` (`Kasa1976`).

## Core claim (as understood via the existing verified implementation, not the source text)
A circle `(x-a)^2 + (y-b)^2 = r^2` expands to `x^2+y^2 = 2ax + 2by + (r^2-a^2-b^2)`, which is
*linear* in the unknowns `[2a, 2b, (r^2-a^2-b^2)]` and solvable by ordinary least squares —
avoiding a nonlinear optimization a direct geometric fit would need. This is exactly the algorithm
already implemented and validated in `quadrature-interferometer-sim` (0.0395% displacement RMS
error, 0.0019% vibration-frequency error on that project's test case) and ported into
`hoqi-bench` as Method 2 on Day 16, with those exact numbers as the port's acceptance test.

## What it does NOT address
- Assumes the (I, Q) trajectory is a genuine circle. This assumption is exactly what breaks once
  any of the Week 2 ellipse distortions (amplitude imbalance, quadrature phase error, DC offset)
  are present — the whole reason this benchmark exists. See Day 16's journal entry for the intended
  explanation of this failure mode.
- Like the algebraic ellipse fits above, minimizes algebraic (not geometric) distance, and is
  known (from general numerical-fitting literature, not this paper specifically) to become
  ill-conditioned on data spanning only a small arc — the "partial arc coverage" failure mode
  already characterized empirically in the prior `quadrature-interferometer-sim` project's
  extension work (see that repo's `report/validation_report.md`, "Nonlinearity-corrected pipeline"
  section).

  Taubin 1991 or Kok/Köning 2014 (both of which are about *improving on* exactly this kind of bias)
  rather than from Kåsa's own paper.
